## Kết quả kiểm chứng

- Trước sửa: 77 test có sẵn chạy qua. Test mới tái hiện được lỗi đọc CV và mật khẩu yếu.
- Sau sửa: PostgreSQL chạy **97/97 test thành công**, gồm 3 test concurrency thật.
- SQLite: **94 test thành công**, 3 test khóa dòng được bỏ qua có chủ đích.
- Có test luồng apply → đổi trạng thái → email, rollback không gửi email,
  SMTP lỗi vẫn giữ application, seed không reset mật khẩu, CSRF và phân quyền.
- Django check, migration drift check, flake8, black, isort, pip check và kiểm tra
  cú pháp JavaScript đều thành công.
- Production check và collectstatic chạy được với biến môi trường kiểm thử và
  thư mục static tạm. Còn cảnh báo W021 do chưa bật HSTS preload; chỉ quyết định
  preload khi đã có domain và chính sách HTTPS phù hợp.
- Đã áp dụng hai migration validator mới trên database local theo settings dev.
  SQL của hai migration là no-op; không xóa/biến đổi dữ liệu CV và application.
- PostgreSQL test dùng database tên riêng, tạo/xóa bởi Django test runner.

## Giới hạn và ưu tiên tiếp theo

1. Email vẫn đồng bộ và chưa retry tự động; cần outbox/worker khi phải bảo đảm giao
   thông báo. Thay đổi status trực tiếp trong Admin chưa gửi email.
2. Trước khi mở public, cần giới hạn đăng nhập/request, SMTP thật, backup/restore,
   thu gom log và staging. Chưa chạy Docker build, gửi SMTP thật hay kiểm tải.
3. Validator header PDF không thay thế quét mã độc. Cần chính sách giữ/xóa CV và
   dọn file mồ côi; upload ảnh chưa có giới hạn dung lượng riêng ở form.
4. Không áp thêm ràng buộc unique email vào DB ngay: form đã kiểm tra, nhưng dữ
   liệu cũ có thể có email trùng/khác hoa thường. Cần rà dữ liệu và thống nhất
   chính sách trước khi migration để tránh làm hỏng quá trình nâng cấp.
5. Các trang chính đã render qua HTTP test client; chưa thực hiện kiểm tra giao
   diện bằng trình duyệt thật hoặc kiểm thử accessibility đầy đủ.
